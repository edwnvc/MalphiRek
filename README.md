# MalphiRek

Plugin para treinar as mecânicas das ultimates do Final Fantasy XIV.

## Instalação

1. No jogo, digite `/xlsettings` e abra a aba **Experimental**.
2. Em **Custom Plugin Repositories**, cole o link abaixo, clique no **+** e depois em **Save**:
   https://raw.githubusercontent.com/edwnvc/MalphiRek/master/repo.json
3. Digite `/xlplugins`, procure por **MalphiRek** e instale.
